
# AT01 - Programação Orientada a Objetos (POO)

## 1. Desafio Profissional

A empresa pediu para cadastrar clientes e funcionários.

### 1.1. Você criaria uma classe só ou mais de uma?

Mais de uma.

- Classe Clientes
- Classe Funcionários

### 1.2. Quais atributos seriam diferentes?

**Clientes:**

- Histórico de compras
- Score
- Formas de pagamento

**Funcionários:**

- Cargo
- Salário
- Data de admissão
- Departamento
- Saldo de horas
- Benefícios

---

## 2. Exercícios de Apropriação

Identifique no código:

- **Classe:** Uma classe ´um modelo que define: caracteristicas (atributos) e comportamentos (metodos).

- **Objeto:** Um objeto é uma instancia da classe, ou seja, um produto especifico.

- **Atributos:** Os atributos são variaveis dentro da classe que guardam informações (caracteristicas).

- **Métodos:** Metodos sao funções dentro da classe.

### 2.1. Explique com suas palavras o que é `$this`

**Resposta:** É utilizado para referenciar o objeto.

---

## 3. Exercícios de Aplicação

Crie uma classe chamada `Produto` com:

- Atributo `nome`
- Atributo `preco`
- Método `mostrarProduto()`

**Atividade:** Instancie dois produtos diferentes utilizando a classe `Produto`.
